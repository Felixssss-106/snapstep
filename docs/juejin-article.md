我开源了一个工具：按一次快捷键，把屏幕操作自动变成图文教程

## 痛点

写操作手册、软件教程、SOP 的传统流程是：截图 → 编号 → 粘进文档 → 写步骤 → 调格式。
一篇 10 步的教程半小时起步，截完图还得回头标注「点这里」「输入那个」。

所以我做了 SnapStep（MIT 开源）：按一次快捷键正常干活，再按一次，
刚才的操作自动变成带标注截图的图文教程。

【图：上传 docs/demo.gif】

## 它是怎么工作的

1. 常驻托盘，`Ctrl+Alt+S` 开始/停止录制
2. 每次左键点击自动成为一个步骤：截屏、记录点击位置和前台窗口、键入的文本自动归进步骤
3. 停止后自动导出 **Markdown / 单文件 HTML（截图 base64 内嵌，发微信直接是成品页）/ Word**
4. 导出时自动在截图上叠加点击高亮圈和步骤序号

## 几个实现细节

**双帧截屏 + 自动选片。** 固定延迟截屏两头不讨好：秒关的对话框截不到，
慢加载的页面截到半成品。v0.2 改成每次点击拍两帧——
**立即帧**（点击后 60ms，就是用户点击时看到的界面）+
**稳定帧**（每 150ms 轮询比对画面，96×54 灰度均值差连续两帧几乎不变即认为稳定）。
停止录制时统一选片：立即帧与上一步画面几乎相同、而稳定帧差异明显
（典型：点了链接等页面加载），自动改用稳定帧。

**无效点击过滤。** 连点空白处、点了没反应的操作会产生垃圾步骤。
停止时逐帧比对相邻步骤截图，画面无变化且没有键入的点击自动剔除并重新编号。

**隐私是底线。** 全程本机处理、零遥测；密码框通过 UI Automation 尽力检测，
键入内容以 •••• 代替；隐私模式一键完全不截屏。
AI 接口地址做了 SSRF 加固：协议白名单、屏蔽云元数据段、禁止重定向，API key 不会被转发。

**AI 文案可插拔。** 默认本地模板生成每步文案（零配置可用）；配置任意 OpenAI 兼容接口
（GLM / DeepSeek / OpenAI / 本地 Ollama）后由大模型润色标题和步骤描述，
调用失败自动退回模板——教程永远能生成。

## 技术栈与两个踩坑

Python 3.10+ / PySide6（托盘与设置）/ pynput（全局钩子）/ mss（截屏）/
Pillow（标注）/ python-docx + Jinja2（导出），PyInstaller 打包单文件 exe，
GitHub Actions 在每个 tag 自动构建发布。

两个印象深的坑：

- PySide6 的 QAction 不挂 parent 会在初始化函数返回后被 GC 回收，
  托盘菜单表面正常、实际只剩第一项——直到遍历菜单子树才发现
- 部分 pynput 构建的 GlobalHotKeys 会忽略注入事件，热键最终改用
  Win32 RegisterHotKey 原生注册才稳定
